## Purpose

Harnett Mesh is a community communications initiative for Harnett County,
North Carolina. It is intended to provide an additional method of text
communication that can operate without cellular service or Internet access,
using shared MeshCore and LoRa-based infrastructure.

The project is currently in planning and early development. This repository is
the public source of truth for its documentation and standards.

## Community benefit

The network is meant to be understandable and useful to ordinary community
members, not only radio operators or networking specialists. A clear onboarding
path, shared standards, coverage information, and respectful channel practices
can make off-grid communication approachable.

## Everyday use is the foundation

**Don't build an emergency network people have never used.**

Harnett Mesh should support normal, everyday communication and experimentation
before an emergency occurs. Regular use gives participants a chance to learn
their devices, understand coverage limits, practice message etiquette, and
discover problems while conditions are normal. That familiarity can make the
network a more useful additional capability when conventional communications
are degraded or unavailable.

## Resilience benefit

Mesh communication may provide another path for short text messages when
cellular or Internet services are unavailable. It is not guaranteed to work in
every location or situation. Terrain, hardware, antennas, power, congestion,
weather, and other radio-frequency conditions affect results.

Harnett Mesh is not an emergency dispatch system and should not be used to
contact 911. It does not replace public-safety communications, amateur-radio
emergency networks, or established emergency procedures.

## Role of Harnett County AuxComm

Members of Harnett County AuxComm are developing and coordinating the project.
AuxComm provides a community of volunteers with experience in communications,
preparedness, and responsible operations. Harnett Mesh is not thereby an
official Harnett County government service; its organizational status and
operating responsibilities should be described carefully as the project grows.

## How the network works at a high level

A compatible device uses a low-power LoRa radio to exchange small data messages
with nearby devices. MeshCore software helps devices participate in a mesh,
where messages may be relayed through other participating infrastructure or
devices when a direct path is not available. A phone may provide the user
interface, while the radio provides the off-grid link.

The exact devices, settings, channels, routing behavior, and infrastructure
roles are still being established. See the documentation marked **TBD** rather
than assuming that examples are final standards.

When the project is ready for community onboarding, continue to
[Getting Started](getting-started.md) to learn how participation is expected to
work.

## Project principles

- **Useful before urgent:** Encourage normal use and learning before an outage.
- **Accessible by design:** Explain the system in plain language and support
  beginners.
- **Honest about limits:** Do not promise coverage, delivery, privacy, or
  availability that has not been demonstrated.
- **Public by default, sensitive by design:** Publish useful standards and
  generalized coverage while protecting private infrastructure information.
- **Evidence over assumption:** Base technical and coverage claims on documented
  tests or reliable references.
- **Community stewardship:** Make decisions transparently and welcome
  constructive contributions.
- **Complement, not replacement:** Treat Harnett Mesh as an additional
  communications capability, not a replacement for emergency services.
