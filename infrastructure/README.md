# Infrastructure Documentation

[Home](../README.md) | [Documentation Index](../docs/README.md)

This public repository uses a public/private documentation model. It should
document how the service works without exposing information that could identify
or compromise protected infrastructure.

This page describes the types and roles of infrastructure supporting Harnett
Mesh without publishing sensitive physical infrastructure information.

## This public repository may contain

- General descriptions of infrastructure
- Infrastructure roles
- General service areas
- Public network standards
- Sanitized operational status

## This public repository must not contain

- Exact coordinates
- Exact site locations
- Credentials or administration keys
- Private configuration
- Infrastructure access instructions
- Sensitive operational information

Detailed operational infrastructure documentation should be maintained
separately in a private repository or other controlled system with appropriate
access controls. Public documents should be reviewed for accidental disclosure
before publication.
